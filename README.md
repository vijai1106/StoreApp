# Grocery Shopping iOS App

An iOS application that allows users to browse grocery products, view detailed descriptions, adjust quantities, and add items to a shopping cart. The app focuses on a clean UI and smooth user experience for everyday grocery shopping.

## 📱 Screens
- Product detail screen with price and quantity controls
- Detailed product description
- Add to Cart functionality
- Cart indicator with item count

## 🚀 Features
- Browse grocery items
- View product details and descriptions
- Increase / decrease product quantity
- Dynamic price calculation based on quantity
- Add items to cart
- Cart badge indicator
- Smooth and responsive UI

## 🛠 Tech Stack
- **Language:** Swift
- **UI Framework:** UIKit
- **Architecture:** MVVM
- **IDE:** Xcode
- **iOS Version:** iOS 13+

## 📐 App Architecture
The app follows a modular structure to separate UI, business logic, and data handling, making it easy to scale and maintain.
